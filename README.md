# Lore Engine

An AI-powered RPG with dynamic storytelling across 4 unique settings.

## Settings
- ☢️ Post-Apocalyptic
- ⚔️ Fantasy
- 🚀 Sci-Fi
- 🤖 Cyberpunk

## Tech Stack
- React + Vite
- Tailwind CSS v4
- Claude Sonnet API (AI Narrator)
- localStorage (Save System)

## Getting Started
```bash
npm install
npm run dev
```
